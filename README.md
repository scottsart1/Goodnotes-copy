# Inkwell

An S Pen-first note-taking app for large Android tablets (built for the Samsung Galaxy Tab S11 Ultra):
handwriting with a side-button eraser, PDFs, OCR, audio recording synced to notes, bring-your-own-key AI
(OpenAI, Anthropic, DeepSeek, Moonshot/Kimi), automatic `YYYYMMDD_Topic` file naming, and a private
notes vault on yourpitbox.com.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the code layout and [docs/VAULT_API.md](docs/VAULT_API.md)
for the vault protocol.
